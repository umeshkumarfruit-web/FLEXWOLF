# Phase 11.4 Production App Release Readiness

## Android

- Release APK and AAB are generated by Flutter from the existing Android project.
- Version code and version name remain sourced from `pubspec.yaml` through Flutter Gradle values.
- Release manifest declares the launcher app name, launcher icon, notification permission, custom scheme deep links, and verified HTTPS app links.
- No signing keys, keystores, or key properties are committed.
- Deep link host defaults to `flexwolf.com` and can be overridden with Gradle property `FLEXWOLF_DEEP_LINK_HOST`.

## iOS

- Bundle identifier is prepared as `com.flexwolf.flexwolf`.
- App version and build number are sourced from Flutter build settings.
- `Runner.entitlements` prepares production push notifications and associated domains.
- `Info.plist` prepares the `flexwolf` URL scheme.
- iOS signing, provisioning, and App Store Connect credentials remain client-owned and are not committed.

## App Assets

- Android launcher icon exists in density-specific mipmap folders.
- Android splash screen uses existing launch background resources.
- Android app name is centralized in `android/app/src/main/res/values/strings.xml`.
- iOS app icon set exists with required icon assets.
- iOS launch image set exists.
- Adaptive icon foreground/background assets are still a client asset dependency if Play Console branding requires adaptive icon customization beyond the current launcher icon.

## Deep Links

Prepared routes:

- Products: `/products/{handleOrId}`
- Collections: `/collections/{handleOrId}`
- Orders: `/account/orders/{orderId}`
- Wishlist: `/wishlist`
- Notification payloads reuse the same deep link parser and reject unsupported routes.

## Push Notifications

- Android declares `POST_NOTIFICATIONS`.
- Firebase messaging remains behind `FirebaseMessagingGateway`.
- Foreground notifications, notification opens, initial notification, token refresh, and token deletion are represented by existing boundaries.
- Background delivery requires final Firebase Android/iOS configuration from the client.

## Store Checklist

Android:

- Build AAB with `flutter build appbundle`.
- Configure Play App Signing outside the repository.
- Provide privacy policy URL.
- Provide terms URL.
- Provide store listing screenshots.
- Provide app category, content rating, data safety, and target audience declarations.
- Verify Digital Asset Links for `https://flexwolf.com`.

IOS:

- Build on macOS with `flutter build ios --release --no-codesign` for unsigned verification.
- Configure signing certificate and provisioning profile outside the repository.
- Provide privacy policy URL.
- Provide terms URL.
- Provide App Store screenshots.
- Configure Associated Domains for `applinks:flexwolf.com`.
- Enable Push Notifications capability in Apple Developer portal.

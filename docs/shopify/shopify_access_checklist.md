# Shopify Client Access Checklist

Statuses: AVAILABLE, NOT AVAILABLE, CLIENT ACTION REQUIRED, NOT REQUIRED YET.

| Item | Status | Notes |
| --- | --- | --- |
| Shopify store domain | CLIENT ACTION REQUIRED | Needed for Storefront and Customer discovery. |
| myshopify.com domain | CLIENT ACTION REQUIRED | Needed if selected endpoint/config requires it. |
| Shopify collaborator/developer access | CLIENT ACTION REQUIRED | Use official invite/team access, not passwords. |
| Apps/channels permission | CLIENT ACTION REQUIRED | Required to configure Headless/custom app access. |
| Headless sales channel access/configuration | CLIENT ACTION REQUIRED | Required for Storefront token/config. |
| Storefront configuration | CLIENT ACTION REQUIRED | Required before real data testing. |
| Customer Accounts enabled/configurable | CLIENT ACTION REQUIRED | Required before auth testing. |
| API application configuration access | CLIENT ACTION REQUIRED | Required for client IDs, redirect URIs, scopes. |
| Checkout configuration access | CLIENT ACTION REQUIRED | Required before Checkout Kit work. |
| Shopify Markets configuration access | NOT REQUIRED YET | Needed for international/markets later. |

SHOPIFY CLIENT ACCESS: CLIENT ACTION REQUIRED

Do not request the client's Shopify password. Use collaborator/developer/team
access through Shopify's official mechanisms.
